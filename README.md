# Shamol Shop — Next.js e-commerce UI

A clean e-commerce storefront UI built with Next.js (App Router) and TypeScript: product grid, category filter, search and a slide-out cart.

## Features
- Product listing with categories (Sneakers, Accessories, Outerwear)
- Search and category filtering
- Cart drawer — add/remove items, totals
- Typed product model (`types/product.ts`), demo data in `lib/products.ts`

## Stack
Next.js 14 · React 18 · TypeScript · CSS (`app/globals.css`)

## Run
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
